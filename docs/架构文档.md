## 系统概述

Personal Workbench 是一个全栈个人任务管理系统，部署在 Cloudflare 边缘网络上。支持任务管理、习惯打卡、周总结、智能推送、分享等功能。

### 核心功能

1. **任务管理**: 看板/表格双视图，父子任务关系，自动流转
2. **习惯打卡**: 多频率习惯追踪，日历视图，完成率统计
3. **周总结**: 自动汇总 + AI 辅助优化
4. **智能推送**: PushPlus 微信推送 + 邮件通知，Cron 定时触发
5. **分享**: 生成分享链接，支持密码保护
6. **认证**: JWT 无状态认证，用户注册/登录

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | React 18 + TypeScript | SPA 单页应用 |
| 样式 | TailwindCSS 3 | 原子化 CSS |
| 图标 | Lucide React | SVG 图标库 |
| 构建 | Vite 5 | 前端构建工具 |
| 后端框架 | Hono 4 | 轻量 Web 框架，运行在 Workers 上 |
| 数据库 | Cloudflare D1 | SQLite 兼容的边缘数据库 |
| 对象存储 | Cloudflare R2 | 图片上传存储 |
| 部署 | Cloudflare Pages | 前端 + API 一体化部署 |
| 定时任务 | Workers Cron Triggers | 原生 cron 支持 |
| 认证 | JWT (jose) | 无状态 Token 认证 |
| 密码哈希 | PBKDF2 (Web Crypto API) | 安全密码存储 |

## 数据模型

### D1 数据库表 (11 张)

| 表名 | 说明 | 核心字段 |
|------|------|----------|
| `users` | 用户 | id, username, password_hash, display_name |
| `tasks` | 任务 | id, user_id, name, status, priority, task_type, parent_id, assignee, start_date, deadline |
| `task_dependencies` | 任务阻止关系 | task_id, blocked_by_id |
| `task_images` | 任务图片 | id, task_id, name, url, r2_key |
| `habits` | 习惯 | id, user_id, name, frequency, status, weekly_target |
| `daily_logs` | 打卡记录 | id, habit_id, user_id, log_date, completed |
| `weekly_summaries` | 周总结 | id, user_id, week_start, data (JSON) |
| `share_links` | 分享链接 | id, user_id, token, resource_type, resource_id, expires_at |
| `activity_logs` | 活动日志 | id, user_id, action, entity_type, entity_id, metadata (JSON) |
| `app_config` | 系统配置 | key, value (JSON) |

### 任务状态流转

```
收集箱 ──(到达开始日期)──→ 进行中 ──→ 已完成
  │                        │
  └────────────────────────→ 暂停
                           │
                           └──→ 已放弃
```

## 认证机制

```
注册/登录 ──→ 验证密码 (PBKDF2) ──→ 签发 JWT (jose)
                                          │
后续请求 ──→ authMiddleware ──→ 解析 JWT ──→ 提取 user_id
                │
                └── 401 Unauthorized (token 无效/过期)
```

- JWT 密钥通过 Pages Secrets 注入（Production 环境）
- Token 存储在 localStorage，axios 拦截器自动附加
- Token 过期时间 7 天

## 定时任务

通过 Workers Cron Triggers 实现，配置在 `wrangler.toml`：

| Cron 表达式 | UTC 时间 | 北京时间 | 功能 |
|-------------|----------|----------|------|
| `0 0 * * *` | 00:00 | 08:00 | 今日待办提醒 |
| `0 14 * * *` | 14:00 | 22:00 | 今日完成总结 |

## 前端缓存策略

| 缓存类型 | 有效期 | 说明 |
|----------|--------|------|
| fetchTasks 缓存 | 30 秒 | 无筛选条件时缓存任务列表 |
| fetchCombinedData 缓存 | 30 秒 | 缓存组合数据（任务+统计） |
| 缓存清除时机 | - | 任务保存后调用 clearCache() 强制刷新 |
