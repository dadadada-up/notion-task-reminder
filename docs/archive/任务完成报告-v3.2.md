## ✅ 问题分析

通过用户提供的截图，发现了严重的数据不一致问题：

### 问题1：编辑器和预览使用不同的数据结构

**编辑器（旧结构）**：
- 字段：类别、任务描述、目标、完成、备注
- 数据：category, description, target, completed, completion_rate, note

**预览（新结构）**：
- 字段：序号、类型、任务、状态、优先级、备注
- 数据：type, task, status, priority, note

### 问题2：模块编号不一致

**编辑器**：
- 一、本周目标与完成情况
- 二、习惯打卡追踪
- 五、下周重点规划 ❌

**预览**：
- 一、本周目标与完成情况
- 四、下周重点规划 ✅

### 问题3：下周计划缺少字段

**编辑器**：类别、任务、目标
**预览**：序号、类别、任务、目标、关键行动

---

## 🔧 解决方案

### 1. 统一"本周目标"数据结构

#### 修改前（编辑器）
```tsx
// 旧字段
<input value={goal.category} />  // 类别
<input value={goal.description} />  // 任务描述
<input value={goal.target} />  // 目标
<input value={goal.completed} />  // 完成
<input value={goal.note} />  // 备注
```

#### 修改后（编辑器）
```tsx
// 新字段 - 与预览一致
<input value={goal.type || goal.category} />  // 类型
<input value={goal.task || goal.description} />  // 任务
<select value={goal.status}>  // 状态（下拉选择）
  <option>已完成</option>
  <option>进行中</option>
  <option>待办</option>
  <option>已取消</option>
</select>
<select value={goal.priority}>  // 优先级（下拉选择）
  <option>P0 重要紧急</option>
  <option>P1 重要不紧急</option>
  <option>P2 紧急不重要</option>
  <option>P3 不重要不紧急</option>
</select>
<input value={goal.note} />  // 备注
```

### 2. 更新addGoal函数

#### 修改前
```tsx
const newGoal = {
  category: '',
  description: '',
  target: 1,
  completed: 0,
  completion_rate: '0%',
  note: ''
}
```

#### 修改后
```tsx
const newGoal = {
  type: '',
  task: '',
  status: '',
  priority: '',
  note: ''
}
```

### 3. 修复模块编号

将"五、下周重点规划"改为"四、下周重点规划"

### 4. 添加"关键行动"字段

#### 修改前（下周计划）
```tsx
// 字段：类别、任务、目标
<input value={plan.category} />
<input value={plan.task} />
<input value={plan.target} />
```

#### 修改后（下周计划）
```tsx
// 字段：类别、任务、目标、关键行动
<input value={plan.category} />
<input value={plan.task} />
<input value={plan.target} />
<input value={plan.actions || plan.关键行动} />  // 新增
```

### 5. 更新addPlan函数

#### 修改前
```tsx
const newPlan = {
  category: '',
  task: '',
  target: 1
}
```

#### 修改后
```tsx
const newPlan = {
  category: '',
  task: '',
  target: '',
  actions: ''  // 新增关键行动
}
```
