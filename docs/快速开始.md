# 快速开始

本指南帮助你快速搭建 Workbench 本地开发环境并部署到线上。

---

## 环境要求

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | 18+ | 运行时环境 |
| npm | 9+ | 包管理器 |
| Cloudflare 账号 | - | 用于 D1 数据库和部署 |

---

## 本地开发

### 1. 克隆项目

```bash
git clone <your-repo-url>
cd workbench
```

### 2. 启动后端 (Worker)

```bash
cd worker
npm install

# 创建本地环境变量文件
cat > .dev.vars << 'EOF'
JWT_SECRET=dev-jwt-secret-do-not-use-in-production-abc123xyz
PUSHPLUS_TOKEN=your_pushplus_token  # 可选
EOF

# 启动 Wrangler 开发服务器
npx wrangler dev
# Ready on http://localhost:8787
```

> 本地开发使用 Miniflare 模拟 D1 数据库，数据存储在本地，不影响远程数据库。

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev
# Ready on http://localhost:3001
```

Vite 开发服务器会自动将 `/api/*` 请求代理到 `http://localhost:8787`。

### 4. 访问应用

打开浏览器访问 http://localhost:3001

默认测试账号：`dada` / `test123456`

## 首次部署

### 1. 初始化 D1 数据库

```bash
cd worker
npx wrangler d1 execute workbench-db --remote --file=src/db/schema.sql
```

### 2. 构建前端

```bash
cd frontend
npm run build
```

### 3. 部署到 Cloudflare Pages

```bash
npx wrangler pages deploy dist --project-name=workbench --branch=main
```

### 4. 配置 Secrets

在 Cloudflare Dashboard 的 Pages 项目中设置 Production 环境变量：

| Secret | 说明 | 必填 |
|--------|------|------|
| `JWT_SECRET` | JWT 签名密钥（建议 32 位以上随机字符串） | 是 |
| `PUSHPLUS_TOKEN` | PushPlus 微信推送 Token | 否 |
| `DEEPSEEK_API_KEY` | DeepSeek API Key（AI 周总结优化） | 否 |

> 注意：Pages Secrets 仅在 Production 环境生效，Preview 环境无法访问。部署时务必使用 `--branch=main`。

## 数据库管理

### 远程执行 SQL

```bash
# 查询任务数量
npx wrangler d1 execute workbench-db --remote --command="SELECT COUNT(*) FROM tasks"

# 从文件执行
npx wrangler d1 execute workbench-db --remote --file=src/db/schema.sql
```

### 查看数据

```bash
# 查看用户
npx wrangler d1 execute workbench-db --remote --command="SELECT id, username FROM users"

# 查看任务状态分布
npx wrangler d1 execute workbench-db --remote --command="SELECT status, COUNT(*) FROM tasks GROUP BY status"
```

## 常见问题

### Q: 本地启动后登录返回 500？

检查 `worker/.dev.vars` 是否配置了 `JWT_SECRET`，然后重启 wrangler dev。

### Q: 部署后登录返回 500？

确认已在 Cloudflare Dashboard 的 Pages Production 环境设置了 `JWT_SECRET` Secret。

### Q: workers.dev 域名无法访问？

国内网络环境下 `workers.dev` 可能被墙。本项目使用 Pages Functions，通过 `pages.dev` 域名访问。

### Q: 子任务创建后看不到？

确保 `/api/data` 端点正确查询了子任务 ID（非硬编码空数组），且前端保存后调用了 `clearCache()` 清除缓存。

### Q: 如何重置密码？

```bash
# 生成新的 PBKDF2 密码哈希（Node.js）
node -e "
const crypto = require('crypto');
const salt = crypto.randomBytes(16).toString('hex');
crypto.pbkdf2('新密码', salt, 100000, 64, 'sha256', (err, key) => {
  console.log('salt:', salt);
  console.log('hash:', key.toString('hex'));
});
"

# 更新 D1
npx wrangler d1 execute workbench-db --remote \
  --command="UPDATE users SET password_hash='pbkdf2:hex:新hash:新salt' WHERE username='dada'"
```
