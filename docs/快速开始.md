## 📋 主要变化

### 1. 新的配置管理系统

**位置**: `backend/core/config.py`

**特性**:
- ✅ 类型安全（使用 Pydantic）
- ✅ 自动验证
- ✅ 配置状态检查
- ✅ 脱敏处理

**使用示例**:
```python
from backend.core.config import get_settings

# 获取配置
settings = get_settings()

# 访问配置
notion_token = settings.notion.token
has_pushplus = settings.push.has_pushplus()
email_ready = settings.email.is_configured()
```

### 2. 测试文件重组

**新结构**:
```
tests/
├── integration/       # 集成测试
├── scripts/          # 测试脚本
├── outputs/          # 测试输出
├── quick_test.py     # 快速测试
└── run_tests.sh      # 统一入口 ⭐
```

**运行测试**:
```bash
cd tests
./run_tests.sh
```

### 3. 前端配置界面增强

**新功能**:
- ✅ 配置状态指示器（已配置/未配置/未启用）
- ✅ 表单验证和错误提示
- ✅ 支持 WxPusher 配置
- ✅ 更友好的用户界面

**访问方式**:
1. 启动服务: `./start.sh`
2. 打开浏览器: http://localhost:5000
3. 点击「系统配置」按钮

## 🔧 配置管理

### 查看配置状态

访问 Web 界面的「系统配置」页面，可以看到：

```
● Notion 配置          ✓ 已配置
● 推送配置             ✓ 已配置
● 邮箱配置             ⚠️ 未配置
● GitHub 配置          ✓ 已配置
```

### 更新配置

1. **通过 Web 界面**（推荐）:
   - 访问 http://localhost:5000
   - 点击「系统配置」
   - 修改配置并保存

2. **手动编辑 .env 文件**:
   ```bash
   vim .env
   ```

3. **使用 API**:
   ```bash
   curl -X PUT http://localhost:5000/api/config \
     -H "Content-Type: application/json" \
     -d '{"notion": {"token": "new_token"}}'
   ```

## ⚠️ 常见问题

### Q1: 启动时报错 "No module named 'pydantic'"

**解决方法**:
```bash
source venv/bin/activate
pip install pydantic==2.5.0
```

### Q2: 配置保存后不生效

**解决方法**:
1. 重启服务器
2. 或者使用 API 重新加载配置

### Q3: 测试文件找不到

**说明**: 测试文件已移动到 `tests/` 目录

**新位置**:
- `test_notification.py` → `tests/integration/test_notification.py`
- `test_schedule_api.py` → `tests/integration/test_schedule_api.py`
- `test_*.sh` → `tests/scripts/test_*.sh`

### Q4: 前端配置界面显示异常

**检查**:
1. 确保后端服务正在运行
2. 检查浏览器控制台错误
3. 清除浏览器缓存
