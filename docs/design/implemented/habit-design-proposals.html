3 种方案，从轻量到重量级，满足不同管理深度需求

方案一：卡片内联管理

★ 推荐

核心理念：在现有打卡卡片上 hover 显示操作按钮，底部折叠展示已暂停/已失效习惯。
优点：改动最小，不打断打卡心流，hover 出现操作按钮不干扰日常使用。
适合场景：习惯数量 < 15 个，管理操作不频繁。

方案二：Tab 分区管理

方案 B

核心理念：将「打卡」和「管理」拆成两个 Tab 页签，管理 Tab 用表格展示所有习惯的完整信息和操作。
优点：管理功能强大，信息密度高，适合批量操作。
缺点：多了一层切换，编辑需要弹窗配合。

方案三：列表 + 侧滑详情面板

方案 C

核心理念：左侧保持打卡列表，点击习惯后右侧滑出详情面板，面板内提供编辑/暂停/删除等完整操作。
优点：信息展示最丰富（含迷你日历、详细统计），操作集中不弹窗。
缺点：布局变化最大，窄屏体验下降，开发量最大。

★ 推荐方案一：卡片内联管理

理由：你的习惯打卡页面核心场景是快速打卡，管理是低频操作。方案一在现有布局上改动最小—— hover 卡片时右上角出现编辑/暂停图标，底部折叠区展示暂停和失效的习惯。 日常打卡完全不受影响，管理时 hover 即可操作。编辑复用已有的 HabitModal 弹窗（改为支持编辑模式）， 不需要重新设计布局，开发量最小，风险最低。
