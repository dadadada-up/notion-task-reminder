## ✅ 问题分析

用户反馈"一、本周目标与完成情况"表格的数据应该直接从Notion数据库获取，但发现数据显示不正确。

### 问题根源

后端代码中使用了错误的字段名：

**错误的映射**：
```python
'type': task.get('type', '未分类')  # ❌ Notion中没有'type'字段
'note': task.get('note', '')  # ❌ Notion中是'notes'字段
```

**Notion实际返回的字段**：
- `task_type` - 任务类型（健康、工作、家庭生活等）
- `name` - 任务名称
- `status` - 状态（已完成、进行中等）
- `priority` - 优先级（P0、P1、P2、P3）
- `notes` - 备注

---

## 🔧 解决方案

### 修复字段映射

#### 修改前
```python
def _generate_goals_from_tasks(self, tasks: List[Dict], by_type: Dict) -> List[Dict]:
    goals = []
    for task in tasks:
        goals.append({
            'type': task.get('type', '未分类'),  # ❌ 错误字段
            'task': task.get('name', ''),
            'status': task.get('status', ''),
            'priority': task.get('priority', ''),
            'note': task.get('note', '')  # ❌ 错误字段
        })
    return goals
```

#### 修改后
```python
def _generate_goals_from_tasks(self, tasks: List[Dict], by_type: Dict) -> List[Dict]:
    goals = []
    for task in tasks:
        goals.append({
            'type': task.get('task_type', '未分类'),  # ✅ 正确字段
            'task': task.get('name', ''),
            'status': task.get('status', ''),
            'priority': task.get('priority', ''),
            'note': task.get('notes', '')  # ✅ 正确字段
        })
    return goals
```

## 🎯 数据获取规则

系统会自动从Notion获取本周的任务，包含两种情况：

### 情况1：任务时间在本周范围内
- 开始时间 ≤ 本周结束
- 截止时间 ≥ 本周开始

### 情况2：任务在本周完成
- 完成时间在本周范围内
- 即使任务计划在其他周，但本周完成了也会显示
